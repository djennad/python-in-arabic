# ساحة أفعى (محرر الويب)

محرر ويب للغة أفعى يعمل بالكامل في المتصفح، ويُنشر تلقائيًا على GitHub Pages
عند كل دمج في الفرع `main` (انظر `.github/workflows/pages.yml`).

الموقع صفحتان:

- **`index.html`**: المحرر (ساحة أفعى).
- **`app.html`**: صفحة التطبيق المستقل. تشغّل برنامجًا على كامل الصفحة دون محرر، وتأخذه
  من الرابط (`app.html#code=...`) أو من ملف `program.af` بجانبها (في المواقع المُصدَّرة).

## التطوير المحلي

يتطلب Node.js 20+ وبايثون 3.10+:

```bash
cd web
npm ci
python3 build.py --serve     # ثم افتح http://localhost:8000
```

أعد تشغيل الأمر بعد كل تعديل (البناء يستغرق أقل من ثانية). البناء الأول وحده أطول
(دقيقة أو اثنتان) لأنه ينزّل توزيعة Pyodide الخاصة بـ Streamlit إلى `web/.cache`.

## الاختبارات

```bash
npx playwright-core install chromium   # مرة واحدة
python3 build.py --serve &
node tests/e2e.mjs    # المحرر
node tests/gui.mjs    # مكتبة «واجهات» والتطبيقات المستقلة والتصدير
node tests/streamlit.mjs   # تطبيقات «ستريمليت» في المحرر والنافذة المستقلة والتصدير
```

## البنية

|---|---|

| `src/runtime.js` | إدارة عامل الخلفية (مشترك بين الصفحتين) |
| `src/worker.js` | عامل خلفية يشغّل بايثون (Pyodide) ومترجم أفعى ويوصل أحداث الواجهة |
| `src/ui.js` | عارض الواجهات: يحوّل عمليات مكتبة «واجهات» إلى عناصر في الصفحة |
| `src/console.js` | لوحة المخرجات مع مراعاة اتجاه النص |
| `src/share.js` | ترميز البرامج في الروابط |
| `src/export.js` | التصدير كموقع مستقل (zip) |
| `streamlit.html`، `src/streamlit-app.js`، `src/streamlit.css` | صفحة تطبيقات «ستريمليت» (stlite) وتعريب مظهرها |
| `streamlit_build.py` | تجهيز بيئة Streamlit للمتصفح: Pyodide 0.29.3 مصغّرة وstlite |
| `src/tokens.css`، `ui.css`، `style.css`، `app.css` | الخطوط والألوان، وعناصر الواجهات، والمحرر، والتطبيق المستقل |
| `build.py` | البناء: يجمّع الملفات في `dist/` مع Pyodide وحزمة أفعى والقاموس والأمثلة |
| `tests/` | اختبارات في متصفح حقيقي |

## كيف يرتبط المحرر باللغة

- **القاموس:** `build.py` يولّد `vocabulary.json` من `afaa/vocabulary.py`، ومنه
  يأتي التلوين والإكمال التلقائي. أي كلمة تُضاف إلى القاموس تظهر في المحرر تلقائيًا.
- **التشغيل:** حزمة `afaa` نفسها (مع مكتبة `afaa/lib/واجهات.af`) تُحمَّل داخل بايثون
  في المتصفح، فالترجمة ورسائل الأخطاء مطابقة لما يحدث على جهازك.
- **الأمثلة:** ملفات `examples/*.af` و`examples/gui/*.af` تظهر في قائمة الأمثلة.

## كيف تعمل مكتبة «واجهات» في المتصفح

1. المكتبة تضيف «عمليات» (أنشئ زرًا، غيّر نصًا، ارسم خطًا...) إلى طابور في
   `afaa/gui_bridge.py`.
2. بعد كل تنفيذ يرسل العامل الطابور إلى الصفحة، فيحوّله `ui.js` إلى عناصر.
3. أحداث المستخدم (ضغطة، كتابة، نبضة مؤقت) تعود إلى العامل فيستدعي دالة المستخدم،
   ثم تُرسل العمليات الناتجة. الكتابة المتسارعة ونبضات المؤقتات تُدمج حتى لا تتراكم.

## كيف تعمل «ستريمليت» في المتصفح

- [stlite](https://github.com/whitphx/stlite) يشغّل Streamlit كاملة داخل المتصفح على
  Pyodide 0.29.3 (غير إصدار Pyodide الذي يستخدمه المحرر)، في صفحة مستقلة `streamlit.html`.
- `streamlit_build.py` لا ينشر توزيعة Pyodide كاملة، بل النواة والحزم التي تحتاجها
  Streamlit فقط (نحو ٢٦ ميغابايت) مع حزم بايثونية خالصة ناقصة من PyPI (ببصمات مُتحقَّق منها)،
  فلا يتصل الموقع بأي خدمة خارجية.
- في المحرر، البرامج التي تستورد `ستريمليت` تعمل في إطار (`streamlit.html?embed`) داخل
  لسان «الواجهة». التشغيل الأول يحمّل البيئة، والتشغيلات التالية ترسل البرنامج برسالة
  فيكتب stlite ملف التطبيق من جديد ويعيد Streamlit التشغيل خلال أقل من ثانية.
- البرنامج يُضمَّن في سكربت بايثون صغير يستدعي `afaa.streamlit_runner.run_source`، الذي
  يترجمه ويعرض أخطاءه بالعربية.

## ملاحظات تقنية

- البرنامج يعمل في عامل خلفية (Web Worker)، فلا تتجمد الصفحة مع الحلقات
  اللانهائية، وزر «إيقاف» ينهي العامل ويبدأ غيره.
- الإدخال `أدخل()` يتطلب `SharedArrayBuffer`، أي عزل الأصل (COOP/COEP).
  GitHub Pages لا يتيح ضبط الترويسات، لذلك يضيفها `coi-serviceworker`
  (تُعاد تحميل الصفحة مرة واحدة عند أول زيارة).
- Pyodide والخطوط مستضافة مع الموقع نفسه، فلا اعتماد على خدمات خارجية. لذلك يعمل
  الموقع المُصدَّر على أي استضافة ملفات ثابتة.
