# قواعد البيانات: SQL بالعربية

مكتبة **قواعد_البيانات** تحفظ بيانات برامجك في قاعدة بيانات SQLite، وتكتب استعلاماتها
**بالعربية**:

```python
من قواعد_البيانات استورد قاعدة_بيانات

ق = قاعدة_بيانات("مدرستي")
ق.نفذ("أنشئ جدول إذا لم يوجد الطلاب (الاسم نص غير فارغ، العمر عدد_صحيح)")
ق.نفذ("أدخل إلى الطلاب القيم (؟، ؟)"، "أحمد"، ١٦)

لكل طالب في ق.استعلم("اختر * من الطلاب حيث العمر أكبر من ١٥ رتب حسب الاسم"):
    اطبع(طالب["الاسم"]، طالب["العمر"])
```

## أين تُحفظ البيانات

| أين يعمل البرنامج | مكان الحفظ |
|---|---|
| على جهازك (`afaa برنامج.af`) | ملف بجانب البرنامج: `قاعدة_بيانات("مدرستي")` ← `مدرستي.db` |
| في ساحة أفعى أو تطبيق مستقل أو موقع مُصدَّر | ذاكرة المتصفح الدائمة (IndexedDB): تبقى البيانات بعد إغلاق الصفحة |
| `قاعدة_بيانات()` بلا اسم | في الذاكرة فقط، تختفي عند انتهاء البرنامج (مفيدة للتجارب) |

في المتصفح، البيانات **خاصة بكل زائر**: كل من يفتح تطبيقك له نسخته الخاصة على جهازه.

## دوال المكتبة

| الدالة | الوصف |
|---|---|
| `ق.نفذ(الاستعلام، *المعطيات)` | ينفّذ أمرًا (إنشاء، إدخال، تحديث، حذف) ويعيد عدد الصفوف المتأثرة |
| `ق.نفذ_عدة(الاستعلام، قائمة)` | ينفّذ الأمر نفسه لكل عنصر في القائمة (إدخال صفوف كثيرة) |
| `ق.نفذ_الكل(النص)` | ينفّذ عدة أوامر مفصولة بـ `؛` |
| `ق.استعلم(الاستعلام، *المعطيات)` | يعيد قائمة الصفوف الناتجة |
| `ق.استعلم_واحدا(الاستعلام، *المعطيات)` | يعيد أول صف فقط، أو `لاشيء` |
| `ق.قيمة(الاستعلام، *المعطيات)` | يعيد قيمة واحدة، مثل `ق.قيمة("اختر عد(*) من الطلاب")` |
| `ق.آخر_معرف` | معرّف آخر صف أُدخل |
| `ق.الجداول()` | أسماء الجداول |
| `ق.أعمدة("الطلاب")` | أسماء أعمدة جدول |
| `ق.معاملة()` | مجموعة أوامر تُعتمد معًا أو تُلغى معًا، انظر [المعاملات](#المعاملات) |
| `ق.أغلق()` | إغلاق القاعدة (أو استخدم `مع قاعدة_بيانات("...") باسم ق:`) |
| `ترجم_استعلام(الاستعلام)` | يعيد الاستعلام بلغة SQL الإنجليزية، للتعلم |
| `احذف_قاعدة("مدرستي")` | يحذف القاعدة نهائيًا |

**الصفوف** تُقرأ بالاسم: `طالب["الاسم"]` أو `طالب.الاسم`، وتُطبع كقاموس:

```python
طالب = ق.استعلم_واحدا("اختر * من الطلاب حيث الاسم = ؟"، "أحمد")
اطبع(طالب)          # {'الاسم': 'أحمد', 'العمر': 16}
اطبع(طالب.العمر)    # 16
```

## SQL بالعربية

الاستعلامات تُترجم إلى SQL قبل تنفيذها:

```
اختر الاسم، العمر من الطلاب حيث العمر أكبر من ١٥ رتب حسب الاسم
SELECT الاسم, العمر FROM الطلاب WHERE العمر > 15 ORDER BY الاسم
```

- **أسماء الجداول والأعمدة** تُكتب بالعربية كما تريد.
- **النصوص** بين `'...'` لا تُترجم أبدًا: `حيث المدينة = 'من الجزائر'` آمنة.
- **الأرقام العربية** `٠-٩` والفاصلة العربية `،` مقبولة، و`؟` مثل `?`.
- **الكتابة مرنة:** الهمزات والحركات لا تهم، فـ«اختر» و«إختر» سواء، وكذلك «جمّع» و«جمع».
- **الإنجليزية مقبولة** أيضًا، ويمكن خلط اللغتين: `SELECT * من الطلاب`.
- العبارات العربية تتبع ترتيب العربية: `مفتاح أساسي` ← `PRIMARY KEY`.

## أمثلة الاستعلامات

```sql
-- إنشاء جدول
أنشئ جدول إذا لم يوجد الطلاب (
    المعرف عدد_صحيح مفتاح أساسي زيادة تلقائية،
    الاسم نص غير فارغ فريد،
    العمر عدد_صحيح تحقق (العمر بين ٥ و ٣٠)،
    المدينة نص افتراضي 'الجزائر'،
    التسجيل نص افتراضي الوقت الحالي
)

-- إدخال
أدخل إلى الطلاب (الاسم، العمر) القيم ('أحمد'، ١٦)، ('سارة'، ١٥)

-- اختيار وتصفية وترتيب
اختر الاسم، العمر من الطلاب حيث العمر أكبر من أو يساوي ١٥ و الاسم يشبه 'أ%' رتب حسب العمر تنازليا حد ١٠

-- تجميع
اختر المدينة، عد(*) باسم العدد، متوسط(العمر) من الطلاب جمّع حسب المدينة بشرط عد(*) أكبر من ١

-- تحديث وحذف
حدث الطلاب اجعل العمر = العمر + ١ حيث المدينة في ('وهران'، 'عنابة')
احذف من الطلاب حيث العمر هو فارغ

-- ضم جدولين
اختر ط.الاسم، د.الدرجة من الطلاب باسم ط ضم يساري الدرجات باسم د على ط.المعرف = د.الطالب

-- حالة
اختر الاسم، حالة عندما العمر أصغر من ١٨ فإن 'قاصر' وإلا 'بالغ' انتهى باسم الفئة من الطلاب

-- تعديل جدول
عدل جدول الطلاب أضف عمود الهاتف نص
```

## المعطيات: علامة ؟

لا تضع قيم المستخدم داخل نص الاستعلام مباشرة. ضع `؟` ومرّر القيم بعده، فتُعامل كقيم
لا كأوامر، وهذا يحمي من هجمات «حقن SQL»:

```python
ق.نفذ("أدخل إلى الطلاب (الاسم، العمر) القيم (؟، ؟)"، الاسم، العمر)       # قيم منفصلة
ق.نفذ("أدخل إلى الطلاب (الاسم، العمر) القيم (؟، ؟)"، [الاسم، العمر])     # أو قائمة
ق.استعلم("اختر * من الطلاب حيث الاسم = :الاسم"، {"الاسم": "أحمد"})    # أو بالأسماء
```

## المعاملات

كل الأوامر داخل `مع ق.معاملة():` تُعتمد معًا، وإن حدث خطأ تُلغى كلها:

```python
مع ق.معاملة():
    ق.نفذ("حدث الحسابات اجعل الرصيد = الرصيد - ١٠٠ حيث الاسم = 'أحمد'")
    ق.نفذ("حدث الحسابات اجعل الرصيد = الرصيد + ١٠٠ حيث الاسم = 'سارة'")
```

## الأخطاء

الأخطاء بالعربية ومعها الاستعلام الأصلي، وتُلتقط بـ `خطأ_قاعدة_بيانات`:

```python
حاول:
    ق.نفذ("أدخل إلى الطلاب (العمر) القيم (١٦)")
باستثناء خطأ_قاعدة_بيانات باسم خ:
    اطبع(خ)
# العمود «الطلاب.الاسم» لا يقبل قيمة فارغة
#   الاستعلام: أدخل إلى الطلاب (العمر) القيم (١٦)
```

## مع مكتبة «واجهات»

الجدول يعرض نتائج الاستعلام مباشرة، وأسماء الأعمدة تؤخذ منها:

```python
من واجهات استورد *
من قواعد_البيانات استورد قاعدة_بيانات

ق = قاعدة_بيانات("مدرستي")
الجدول = جدول(ق.استعلم("اختر * من الطلاب"))
...
الجدول.اعرض(ق.استعلم("اختر * من الطلاب رتب حسب العمر"))   # تحديث
```

مثال كامل: [examples/gui/students.af](../examples/gui/students.af)، سجل طلاب ببحث وإضافة
وحذف، بيانات تبقى بعد إغلاق الصفحة.

## طرفية SQL

للتعلم والتجربة، افتح طرفية SQL عربية على قاعدة بيانات:

```
$ afaa --sql مدرستي
sql> اختر * من الطلاب رتب حسب العمر؛
الاسم | العمر
------+------
سارة  | 15
أحمد  | 16
(2 صفوف)
sql> .جداول
sql> .ترجم اختر عد(*) من الطلاب
SELECT COUNT(*) FROM الطلاب
```

أنهِ كل استعلام بـ `؛` (يمكن أن يمتد على عدة أسطر). و`afaa --translate-sql "..."` يعرض
ترجمة استعلام دون تنفيذه.

## ملاحظات

- **عمود اسمه كلمة محجوزة:** إن سمّيت عمودًا «جدول» أو «حالة» أو «عد» مثلًا، فضعه بين
  علامتي تنصيص مزدوجتين: `اختر "حالة" من الطلبات`. يُفضّل استخدام أسماء بـ «ال» مثل
  «الحالة»، فهي لا تتعارض مع أي كلمة.
- **حرف «و» منفصل:** اكتب `و الاسم` لا `والاسم`.
- **أكثر من لسان:** في المتصفح، إن فتحت التطبيق نفسه في لسانين وعدّلت البيانات في كليهما،
  فآخر حفظ هو الذي يبقى.
- **التصفح الخاص:** بعض المتصفحات لا تسمح بالتخزين الدائم فيه، فتعمل القاعدة لكن
  البيانات لا تبقى بعد الإغلاق.
- **المكتبة مكتوبة بأفعى:** [afaa/lib/قواعد_البيانات.af](../afaa/lib/قواعد_البيانات.af)،
  والمترجم في [afaa/sql.py](../afaa/sql.py).
