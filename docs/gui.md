# مكتبة «واجهات»: تطبيقات ويب تفاعلية بالعربية

مكتبة **واجهات** تبني تطبيقات ويب تفاعلية بلغة أفعى: أزرار، وحقول إدخال، وجداول،
ولوحات رسم، ومؤقتات. التطبيق يعمل في المتصفح، ويمكن:

- تشغيله في **ساحة أفعى** (لسان «الواجهة»)
- فتحه في **نافذة مستقلة** بلا محرر
- **نشره فورًا برابط** يفتحه أي أحد
- **تصديره كموقع مستقل** (ملف zip) وإستضافته في أي مكان

```python
من واجهات استورد *

عنوان_الصفحة("تحية")
الاسم = حقل_نص(تلميح="ما اسمك؟")
التحية = تسمية("")

دالة حيّ():
    التحية.النص = f"أهلا يا {الاسم.القيمة}!"

زر("حيّني"، حيّ)
```

## كيف تعمل

1. العناصر تظهر في الصفحة **بترتيب إنشائها**.
2. بعد انتهاء الشيفرة **يبقى التطبيق يعمل** وينتظر المستخدم (تظهر الحالة «التطبيق يعمل»).
3. عند الضغط أو الكتابة تُستدعى دوالك، وأي تغيير تجريه على العناصر يظهر فورًا.
4. زر «إيقاف» ينهي التطبيق.

## العناصر

| العنصر | الوصف | مثال |
|---|---|---|
| `ترويسة(النص، المستوى=٢)` | عنوان بارز، المستوى من ١ إلى ٤ | `ترويسة("مرحبا"، المستوى=١)` |
| `تسمية(النص)` | نص قابل للتغيير | `ت = تسمية("٠")` |
| `زر(النص، عند_الضغط، النمط)` | زر، النمط: «أساسي» «ثانوي» «خطر» «نجاح» | `زر("احفظ"، احفظ)` |
| `حقل_نص(تلميح، القيمة، عند_التغيير، عند_الإرسال، سري)` | سطر نصي؛ عند_الإرسال عند ضغط Enter | `حقل_نص(تلميح="اسمك")` |
| `منطقة_نص(تلميح، القيمة، الأسطر، عند_التغيير)` | نص متعدد الأسطر | `منطقة_نص(الأسطر=٦)` |
| `حقل_عدد(القيمة، الأدنى، الأقصى، الخطوة، عند_التغيير)` | إدخال عدد؛ القيمة عدد أو `لاشيء` | `حقل_عدد(٥، الأدنى=٠)` |
| `منزلق(الأدنى، الأقصى، القيمة، الخطوة، عند_التغيير)` | شريط منزلق | `منزلق(٠، ١٠٠، ٥٠)` |
| `مربع_اختيار(النص، محدد، عند_التغيير)` | القيمة `صح` أو `خطأ` | `مربع_اختيار("موافق")` |
| `قائمة_منسدلة(الخيارات، القيمة، عند_التغيير)` | اختيار واحد من قائمة | `قائمة_منسدلة(["أ"، "ب"])` |
| `جدول(الأعمدة، الصفوف)` | جدول بيانات، مع `أضف_صفا(...)` و`اعرض(صفوف)` و`امسح()`، ويقبل نتائج قاعدة بيانات مباشرة: `جدول(ق.استعلم(...))` ([قواعد البيانات](database.md#مع-مكتبة-واجهات)) | `جدول(["الاسم"، "العمر"])` |
| `شريط_تقدم(القيمة، الأقصى)` | نسبة إنجاز | `شريط_تقدم(٣٠)` |
| `صورة(الرابط، العرض، الوصف)` | صورة من الإنترنت | `صورة("https://...")` |
| `رابط(النص، الوجهة)` | رابط يفتح في لسان جديد | `رابط("أفعى"، "https://...")` |
| `خط_فاصل()` | خط أفقي | |
| `لوحة_رسم(العرض، الارتفاع، الخلفية، عند_الضغط)` | مساحة رسم، انظر أدناه | `لوحة_رسم(٤٠٠، ٣٠٠)` |

القيم تُقرأ وتُغيَّر بالخصائص:

```python
حقل = حقل_نص()
اطبع(حقل.القيمة)       # ما كتبه المستخدم
حقل.القيمة = ""        # يمسح الحقل
ت = تسمية("قبل")
ت.النص = "بعد"         # يتغير في الصفحة فورًا
```

## الحاويات والترتيب

استخدم الحاويات مع `مع` لترتيب العناصر:

```python
مع أفقي():                 # صف أفقي
    زر("نعم")
    زر("لا")

مع بطاقة("بياناتك"):       # إطار بعنوان
    حقل_نص(تلميح="الاسم")
    مع شبكة(الأعمدة=٢):     # شبكة من عمودين
        حقل_عدد(٠)
        حقل_عدد(٠)
```

| الحاوية | الوصف |
|---|---|
| `أفقي(المسافة)` | صف أفقي (يلتف على الشاشات الصغيرة) |
| `عمودي(المسافة)` | عناصر فوق بعضها |
| `بطاقة(العنوان)` | إطار بحدود وعنوان اختياري |
| `شبكة(الأعمدة، المسافة)` | شبكة بعدد أعمدة محدد |

يمكن أيضًا إضافة عنصر إلى حاوية لاحقًا بالمعامل `داخل`:

```python
القائمة = عمودي()
...
تسمية("عنصر جديد"، داخل=القائمة)
القائمة.امسح()   # يحذف كل ما بداخلها
```

## الأحداث

| الحدث | العناصر | المعاملات التي تُمرَّر لدالتك |
|---|---|---|
| `عند_الضغط` | زر | لا شيء، أو الزر نفسه |
| `عند_الضغط` | لوحة_رسم | `(س، ص)` موضع النقر |
| `عند_التغيير` | عناصر الإدخال | لا شيء، أو القيمة الجديدة |
| `عند_الإرسال` | حقل_نص | لا شيء، أو النص (عند ضغط Enter) |

دالتك تأخذ ما تحتاجه فقط، فكل هذه صحيحة:

```python
زر("أ"، لامدا: اطبع("ضغطة"))
زر("ب"، لامدا ز: اطبع(ز.النص))
حقل_عدد(عند_التغيير=لامدا ق: اطبع("الجديد:"، ق))
```

ويمكن ضبط الحدث بعد الإنشاء: `حقل.عند_الإرسال = دالتي`

## الخصائص المشتركة والتنسيق

كل العناصر لديها:

| | |
|---|---|
| `العنصر.أخف()` / `العنصر.أظهر()` | إخفاء وإظهار (أو `العنصر.مرئي = خطأ`) |
| `العنصر.عطل()` / `العنصر.فعل()` | تعطيل وتفعيل (أو `العنصر.معطل = صح`) |
| `العنصر.أزل()` | حذف العنصر من الصفحة |
| `العنصر.نسق(...)` | تغيير المظهر، ويعيد العنصر نفسه |

معاملات `نسق`: `اللون`، `الخلفية`، `الحجم` (حجم الخط)، `عريض`، `المحاذاة`
(«يمين» «وسط» «يسار»)، `العرض`، `الارتفاع`، `الحشو`.

```python
تسمية("٠").نسق(الحجم=٤٨، عريض=صح، المحاذاة="وسط"، اللون="أزرق")
```

## لوحة الرسم والسلحفاة

نقطة الأصل (٠، ٠) في الزاوية العليا اليسرى:

```python
ل = لوحة_رسم(٤٠٠، ٣٠٠، الخلفية="أبيض")
ل.ارسم_خطا(٠، ٠، ١٠٠، ١٠٠، اللون="أحمر"، السمك=٣)
ل.ارسم_مستطيلا(٢٠، ٢٠، ٨٠، ٥٠، التعبئة="أصفر")
ل.ارسم_دائرة(٢٠٠، ١٥٠، ٤٠، اللون="أزرق"، التعبئة="سماوي")
ل.ارسم_مضلعا([(١٠، ١٠)، (٥٠، ١٠)، (٣٠، ٤٠)]، التعبئة="أخضر")
ل.ارسم_نصا("مرحبا"، ٢٠٠، ٢٨٠، الحجم=٢٤)
ل.امسح()
```

**السلحفاة** ترسم على لوحة (مثل مكتبة turtle في بايثون). تبدأ في المنتصف متجهة يمينًا:

```python
س = سلحفاة_رسم()            # تنشئ لوحة ٤٠٠×٤٠٠، أو: سلحفاة_رسم(لوحتي)
س.لون("بنفسجي")
لكل _ في مدى(٥):
    س.تقدم(١٥٠)
    س.يمين(١٤٤)
```

أوامرها: `تقدم`، `تراجع`، `يمين`، `يسار`، `اتجه`، `اذهب_إلى(س، ص)`، `دائرة(نصف_القطر)`،
`ارفع_القلم`، `أنزل_القلم`، `لون`، `سمك`.

## الصفحة

## الألوان

تقبل كل معاملات الألوان الأسماء العربية: أحمر، أخضر، أزرق، أصفر، برتقالي، بنفسجي، وردي،
بني، أسود، أبيض، رمادي، سماوي، ذهبي، كحلي، زيتي، فيروزي، شفاف. وتقبل أيضًا أي لون CSS
مثل `"#ff8800"`.

## النشر والتصدير

من لسان «الواجهة» في ساحة أفعى:

| الزر | ماذا يفعل |
|---|---|
| ↗ نافذة مستقلة | يفتح التطبيق وحده في لسان جديد |
| 🔗 رابط التطبيق | ينسخ رابطًا يفتح التطبيق مباشرة لأي أحد، **وهذا نشر فوري مجاني** (البرنامج محفوظ داخل الرابط نفسه) |
| ⬇ تصدير كموقع | ينزّل ملف zip فيه موقع كامل مستقل (نحو ١٠ ميغابايت): التطبيق وبايثون وأفعى |

**نشر الموقع المُصدَّر مجانًا:**

- **GitHub Pages:** أنشئ مستودعًا عامًا، وارفع محتويات الملف المضغوط، ثم
  Settings ← Pages ← Deploy from a branch ← main.
- **Netlify:** اسحب المجلد إلى https://app.netlify.com/drop

الموقع لا يحتاج خادمًا: يعمل في متصفح الزائر بالكامل. التفاصيل في ملف
«اقرأني.txt» داخل الملف المضغوط.

**من سطر الأوامر:** `afaa --web تطبيقي.af` يفتح ملفًا على جهازك كتطبيق ويب،
و`afaa --edit تطبيقي.af` يفتحه في المحرر.

## ملاحظات

- **المكتبة تعمل في المتصفح فقط.** تشغيل برنامج واجهات بالأمر `afaa تطبيقي.af`
  يعطي رسالة توضيحية؛ استخدم `afaa --web تطبيقي.af` بدلًا منه.
- **انتبه لأسماء المتغيرات:** بعض الكلمات مترجمة في القاموس، مثل `حقل` (field) و`نص`
  (str) و`قائمة` (list). المتغير `حقل = حقل_نص()` يعمل، لكن يفضّل اسم مثل `حقل_الاسم`.
- **المكتبة مكتوبة بأفعى نفسها:** [afaa/lib/واجهات.af](../afaa/lib/واجهات.af)، وهي مثال
  جيد على برنامج أفعى كبير.
- **حفظ البيانات:** استخدم مكتبة [قواعد_البيانات](database.md) لتبقى بيانات تطبيقك بعد
  إغلاق الصفحة.
- **الأمثلة:** [examples/gui](../examples/gui) — عدّاد، وحاسبة، وقائمة مهام، وسجل طلاب
  بقاعدة بيانات، ولوحة رسم، وساعة إيقاف.
