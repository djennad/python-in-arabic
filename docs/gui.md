# مكتبة «واجهات»: تطبيقات ويب تفاعلية بالعربية

مكتبة **واجهات** تبني تطبيقات ويب تفاعلية بلغة أفعى: أزرار، وحقول إدخال، وجداول
بالبحث والفرز، ورسوم بيانية، وألسنة، ونوافذ منبثقة، ورفع الملفات وتنزيلها، ولوحات رسم
تستجيب للفأرة ولوحة المفاتيح (للألعاب)، ومؤقتات. التطبيق يعمل في المتصفح، ويمكن:

- تشغيله في **ساحة أفعى** (لسان «الواجهة»)
- فتحه في **نافذة مستقلة** بلا محرر
- **نشره فورًا برابط** يفتحه أي أحد
- **تصديره كموقع مستقل** (ملف zip) وإستضافته في أي مكان

```python
من واجهات استورد *

عنوان_الصفحة("تحية")
الاسم = حقل_نص(تلميح="ما اسمك؟")
التحية = تسمية("")

دالة حيّ():
    التحية.النص = f"أهلا يا {الاسم.القيمة}!"

زر("حيّني"، حيّ)
```

## كيف تعمل

1. العناصر تظهر في الصفحة **بترتيب إنشائها**.
2. بعد انتهاء الشيفرة **يبقى التطبيق يعمل** وينتظر المستخدم (تظهر الحالة «التطبيق يعمل»).
3. عند الضغط أو الكتابة تُستدعى دوالك، وأي تغيير تجريه على العناصر يظهر فورًا.
4. زر «إيقاف» ينهي التطبيق.

## العناصر

| العنصر | الوصف | مثال |
|---|---|---|
| `ترويسة(النص، المستوى=٢)` | عنوان بارز، المستوى من ١ إلى ٤ | `ترويسة("مرحبا"، المستوى=١)` |
| `تسمية(النص)` | نص قابل للتغيير | `ت = تسمية("٠")` |
| `زر(النص، عند_الضغط، النمط)` | زر، النمط: «أساسي» «ثانوي» «خطر» «نجاح» | `زر("احفظ"، احفظ)` |
| `حقل_نص(تلميح، القيمة، عند_التغيير، عند_الإرسال، سري)` | سطر نصي؛ عند_الإرسال عند ضغط Enter | `حقل_نص(تلميح="اسمك")` |
| `منطقة_نص(تلميح، القيمة، الأسطر، عند_التغيير)` | نص متعدد الأسطر | `منطقة_نص(الأسطر=٦)` |
| `حقل_عدد(القيمة، الأدنى، الأقصى، الخطوة، عند_التغيير)` | إدخال عدد؛ القيمة عدد أو `لاشيء` | `حقل_عدد(٥، الأدنى=٠)` |
| `منزلق(الأدنى، الأقصى، القيمة، الخطوة، عند_التغيير)` | شريط منزلق | `منزلق(٠، ١٠٠، ٥٠)` |
| `مربع_اختيار(النص، محدد، عند_التغيير)` | القيمة `صح` أو `خطأ` | `مربع_اختيار("موافق")` |
| `قائمة_منسدلة(الخيارات، القيمة، عند_التغيير)` | اختيار واحد من قائمة | `قائمة_منسدلة(["أ"، "ب"])` |
| `اختيار_واحد(الخيارات، القيمة، أفقي، عند_التغيير)` | خيارات ظاهرة يُختار منها واحد | `اختيار_واحد(["ذكر"، "أنثى"])` |
| `مفتاح_تبديل(النص، مفعل، عند_التغيير)` | مفتاح تشغيل وإيقاف؛ القيمة `صح` أو `خطأ` | `مفتاح_تبديل("الوضع الداكن")` |
| `حقل_تاريخ(القيمة، الأدنى، الأقصى، عند_التغيير)` | تقويم؛ القيمة `datetime.date` | `حقل_تاريخ("2026-10-01")` |
| `حقل_وقت(القيمة، عند_التغيير)` | الساعة والدقيقة؛ القيمة `datetime.time` | `حقل_وقت("09:30")` |
| `منتقي_لون(القيمة، عند_التغيير)` | اختيار لون؛ القيمة مثل `"#9333ea"` | `منتقي_لون("بنفسجي")` |
| `رفع_ملف(النص، عند_الرفع، الأنواع، متعدد)` | اختيار ملف من جهاز المستخدم، انظر [الملفات](#الملفات-الرفع-والتنزيل) | `رفع_ملف(عند_الرفع=اقرأ)` |
| `جدول(الأعمدة، الصفوف، عند_الاختيار، قابل_للبحث، حجم_الصفحة)` | جدول بيانات بالفرز والبحث والصفحات، انظر [الجداول](#الجداول-البحث-والفرز-والاختيار) | `جدول(["الاسم"، "العمر"])` |
| `رسم_بياني(البيانات، النوع، العنوان)` | رسم أعمدة أو خطي أو مساحي أو دائري أو حلقي، انظر [الرسوم البيانية](#الرسوم-البيانية) | `رسم_بياني({"أ": ٣، "ب": ٥})` |
| `شريط_تقدم(القيمة، الأقصى)` | نسبة إنجاز | `شريط_تقدم(٣٠)` |
| `صورة(الرابط، العرض، الوصف)` | صورة من الإنترنت | `صورة("https://...")` |
| `رابط(النص، الوجهة)` | رابط يفتح في لسان جديد | `رابط("أفعى"، "https://...")` |
| `خط_فاصل()` | خط أفقي | |
| `لوحة_رسم(العرض، الارتفاع، الخلفية، عند_الضغط، ...)` | مساحة رسم تستجيب للفأرة واللمس، انظر أدناه | `لوحة_رسم(٤٠٠، ٣٠٠)` |

القيم تُقرأ وتُغيَّر بالخصائص:

```python
حقل = حقل_نص()
اطبع(حقل.القيمة)       # ما كتبه المستخدم
حقل.القيمة = ""        # يمسح الحقل
ت = تسمية("قبل")
ت.النص = "بعد"         # يتغير في الصفحة فورًا
```

## الحاويات والترتيب

استخدم الحاويات مع `مع` لترتيب العناصر:

```python
مع أفقي():                 # صف أفقي
    زر("نعم")
    زر("لا")

مع بطاقة("بياناتك"):       # إطار بعنوان
    حقل_نص(تلميح="الاسم")
    مع شبكة(الأعمدة=٢):     # شبكة من عمودين
        حقل_عدد(٠)
        حقل_عدد(٠)
```

| الحاوية | الوصف |
|---|---|
| `أفقي(المسافة)` | صف أفقي (يلتف على الشاشات الصغيرة) |
| `عمودي(المسافة)` | عناصر فوق بعضها |
| `بطاقة(العنوان)` | إطار بحدود وعنوان اختياري |
| `شبكة(الأعمدة، المسافة)` | شبكة بعدد أعمدة محدد |

يمكن أيضًا إضافة عنصر إلى حاوية لاحقًا بالمعامل `داخل`:

```python
القائمة = عمودي()
...
تسمية("عنصر جديد"، داخل=القائمة)
القائمة.امسح()   # يحذف كل ما بداخلها
```

## الألسنة والنوافذ المنبثقة

**الألسنة** تقسم التطبيق إلى صفحات فرعية. كل لسان حاوية تُملأ بـ `مع`:

```python
الطلاب، الإحصاءات = ألسنة(["👥 الطلاب"، "📊 الإحصاءات"])
مع الطلاب:
    جدول(...)
مع الإحصاءات:
    رسم_بياني(...)
```

- `ألسنة(العناوين، عند_التغيير)`: `عند_التغيير` تُستدعى بعنوان اللسان المختار.
- `ل.لسان("جديد")` يضيف لسانًا، و`ل.الحالي = ١` ينتقل إلى اللسان الثاني.
- عنوان اللسان يتغير بخاصية `العنوان`: `الطلاب.العنوان = "👥 الطلاب (١٢)"`.

**النافذة المنبثقة** تظهر فوق الصفحة، ويغلقها المستخدم بزر ✕ أو بمفتاح Esc:

```python
النافذة = نافذة_حوار("تعديل الطالب"، عند_الإغلاق=لامدا: اطبع("أُغلقت"))
مع النافذة:
    الاسم = حقل_نص()
    زر("احفظ"، لامدا: النافذة.أغلق())

زر("عدّل"، لامدا: النافذة.افتح())
```

و`أكد(الرسالة، عند_الموافقة)` يسأل المستخدم قبل أمر مهم، ويستدعي الدالة إن ضغط «نعم»:

```python
زر("احذف الكل"، لامدا: أكد("هل تريد حذف كل البيانات؟"، احذف_الكل)، النمط="خطر")
```

## الجداول: البحث والفرز والاختيار

```python
الجدول = جدول(الطلاب، قابل_للبحث=صح، حجم_الصفحة=١٠، عند_الاختيار=عدّل)
```

| الخيار | ماذا يفعل |
|---|---|
| الفرز | بالضغط على عنوان أي عمود (مرة تصاعديًا ومرة تنازليًا)، ويعرف الأعمدة الرقمية |
| `قابل_للبحث=صح` | حقل بحث فوق الجدول يصفّي الصفوف أثناء الكتابة |
| `حجم_الصفحة=١٠` | يقسم الصفوف إلى صفحات بأزرار «السابقة» و«التالية» |
| `عند_الاختيار=دالة` | الضغط على صف يستدعي الدالة **بالصف الأصلي كما هو**: قاموس، أو كائن نموذج من قواعد البيانات، أو قائمة |
| `قابل_للفرز=خطأ` | يلغي الفرز |

الصف المختار متاح أيضًا في `الجدول.المحدد`. ولأن الدالة تستقبل كائن النموذج نفسه،
يمكن تعديله وحفظه مباشرة:

```python
دالة عدّل(ط):             # ط كائن من نموذج «طالب»
    ط.العمر += ١
    ط.احفظ()
    الجدول.اعرض(طالب.الكل())
```

## الرسوم البيانية

```python
رسم_بياني({"يناير": ١٢، "فبراير": ١٩، "مارس": ١٥})                       # أعمدة
رسم_بياني({"٢٠٢٥": [...]، "٢٠٢٦": [...]}، التسميات=الأشهر، النوع="خطي")   # سلسلتان
رسم_بياني(ق.استعلم("اختر الصنف، عد(*) باسم العدد من المنتجات جمّع حسب الصنف")،
          س="الصنف"، ص="العدد"، النوع="حلقي")                           # من قاعدة بيانات
```

| المعامل | الوصف |
|---|---|
| `البيانات` | قاموس `{تسمية: قيمة}`، أو `{سلسلة: [قيم]}` مع `التسميات`، أو صفوف قاعدة بيانات مع `س` و`ص`، أو قائمة قيم |
| `النوع` | «أعمدة» (الافتراضي)، «خطي»، «مساحي»، «دائري»، «حلقي» |
| `العنوان` | عنوان فوق الرسم |
| `الارتفاع` | بالبكسل (الافتراضي ٣٠٠) |
| `مكدس=صح` | الأعمدة أو المساحات فوق بعضها بدل جنبًا إلى جنب |

- عند مرور الفأرة يظهر تلميح بالقيم، وللسلاسل المتعددة وسيلة إيضاح بالألوان.
- الألوان مختارة لتبقى مميزة لمن لديهم عمى الألوان، ولها درجات خاصة بالوضع الداكن.
- التحديث: `رسم.اعرض(بيانات_جديدة)`، وتغيير النوع: `رسم.النوع = "خطي"`.

## الملفات: الرفع والتنزيل

**رفع ملف** من جهاز المستخدم (حتى ١٠ ميغابايت):

```python
دالة اقرأ(ملف):
    اطبع(ملف.الاسم، ملف.الحجم، ملف.النوع)
    النص = ملف.كنص()          # المحتوى نصًا
    الصفوف = ملف.كصفوف()      # ملف CSV كقائمة قواميس، جاهزة لـ جدول ورسم_بياني
    البايتات = ملف.المحتوى    # المحتوى الخام (bytes)

رفع_ملف("📂 اختر ملفًا"، عند_الرفع=اقرأ، الأنواع=".csv,.txt")
```

`متعدد=صح` يسمح باختيار عدة ملفات، فتصل الدالة قائمة ملفات. `كصفوف()` يتعرف على
الفاصل تلقائيًا (`,` أو `;` أو `؛`).

**تنزيل ملف** إلى جهاز المستخدم:

```python
نزل_ملف("ملاحظات.txt"، "نص الملف")
نزل_ملف("الطلاب.csv"، ق.استعلم("اختر * من الطلاب"))   # قائمة صفوف ← ملف CSV يفتحه Excel بالعربية
نزل_ملف("صورة.png"، بايتات_الصورة، النوع="image/png")
```

## الأحداث

| الحدث | العناصر | المعاملات التي تُمرَّر لدالتك |
|---|---|---|
| `عند_الضغط` | زر | لا شيء، أو الزر نفسه |
| `عند_الضغط` | لوحة_رسم | `(س، ص)` موضع النقر |
| `عند_الضغط_لأسفل`، `عند_السحب`، `عند_التحريك`، `عند_الإفلات` | لوحة_رسم | `(س، ص)`، انظر [لوحة الرسم](#لوحة-الرسم-والسلحفاة) |
| `عند_الاختيار` | جدول | الصف المضغوط |
| `عند_الرفع` | رفع_ملف | الملف (أو قائمة ملفات) |
| `عند_التغيير` | ألسنة | عنوان اللسان |
| `عند_الإغلاق` | نافذة_حوار | لا شيء |
| `عند_التغيير` | عناصر الإدخال | لا شيء، أو القيمة الجديدة |
| `عند_الإرسال` | حقل_نص | لا شيء، أو النص (عند ضغط Enter) |

دالتك تأخذ ما تحتاجه فقط، فكل هذه صحيحة:

```python
زر("أ"، لامدا: اطبع("ضغطة"))
زر("ب"، لامدا ز: اطبع(ز.النص))
حقل_عدد(عند_التغيير=لامدا ق: اطبع("الجديد:"، ق))
```

ويمكن ضبط الحدث بعد الإنشاء: `حقل.عند_الإرسال = دالتي`

## الخصائص المشتركة والتنسيق

كل العناصر لديها:

| | |
|---|---|
| `العنصر.أخف()` / `العنصر.أظهر()` | إخفاء وإظهار (أو `العنصر.مرئي = خطأ`) |
| `العنصر.عطل()` / `العنصر.فعل()` | تعطيل وتفعيل (أو `العنصر.معطل = صح`) |
| `العنصر.أزل()` | حذف العنصر من الصفحة |
| `العنصر.نسق(...)` | تغيير المظهر، ويعيد العنصر نفسه |

معاملات `نسق`:

| المعامل | مثال |
|---|---|
| `اللون`، `الخلفية` | `اللون="أزرق"`، `الخلفية="#fef3c7"` |
| `الحجم` (حجم الخط)، `عريض`، `مائل`، `الخط` («عادي» أو «ثابت» للشيفرة) | `الحجم=٢٤، عريض=صح` |
| `المحاذاة` («يمين» «وسط» «يسار») | `المحاذاة="وسط"` |
| `العرض`، `الارتفاع`، `الحشو`، `الهامش` (بالبكسل) | `الحشو=١٢` |
| `الحدود`: لون، أو سمك ولون، أو `صح` | `الحدود="٢ أحمر"` |
| `الزوايا` (تدوير الزوايا)، `الظل` (`صح`/`خطأ`)، `الشفافية` (من ٠ إلى ١) | `الزوايا=١٢، الظل=صح` |

```python
تسمية("٠").نسق(الحجم=٤٨، عريض=صح، المحاذاة="وسط"، اللون="أزرق")
بطاقة().نسق(الحدود="٢ فيروزي"، الزوايا=١٦، الظل=صح)
```

## لوحة الرسم والسلحفاة

نقطة الأصل (٠، ٠) في الزاوية العليا اليسرى:

```python
ل = لوحة_رسم(٤٠٠، ٣٠٠، الخلفية="أبيض")
ل.ارسم_خطا(٠، ٠، ١٠٠، ١٠٠، اللون="أحمر"، السمك=٣)
ل.ارسم_مستطيلا(٢٠، ٢٠، ٨٠، ٥٠، التعبئة="أصفر"، الزوايا=٨)
ل.ارسم_دائرة(٢٠٠، ١٥٠، ٤٠، اللون="أزرق"، التعبئة="سماوي")
ل.ارسم_شكلا_بيضويا(٣٠٠، ٥٠، ٥٠، ٢٥، التعبئة="وردي")
ل.ارسم_قوسا(٢٠٠، ١٥٠، ٦٠، ٠، ١٨٠، اللون="بنفسجي")    # الزوايا بالدرجات
ل.ارسم_مضلعا([(١٠، ١٠)، (٥٠، ١٠)، (٣٠، ٤٠)]، التعبئة="أخضر")
ل.ارسم_نصا("مرحبا"، ٢٠٠، ٢٨٠، الحجم=٢٤، عريض=صح)
ل.ارسم_نصا("🍎"، ١٠٠، ١٠٠، الحجم=٣٠)                  # الرموز التعبيرية مفيدة في الألعاب
ل.ارسم_صورة("شعار.png"، ١٠، ١٠، العرض=٦٤)
ل.امسح()
```

`ارسم_صورة` تحافظ على ترتيب الرسم: ما يُرسم بعد الصورة يظهر فوقها حتى لو تأخر تحميلها.
الصور من مواقع أخرى تحتاج أن يسمح موقعها بذلك (CORS)؛ الأسهل صور موقعك نفسه.

**أحداث الفأرة واللمس**، وكل دالة تأخذ إحداثيي النقطة `(س، ص)`:

| الحدث | متى |
|---|---|
| `عند_الضغط` | نقرة كاملة |
| `عند_الضغط_لأسفل` | بداية الضغط |
| `عند_السحب` | الحركة والزر مضغوط (للرسم الحر) |
| `عند_التحريك` | كل حركة فوق اللوحة |
| `عند_الإفلات` | رفع الزر أو الإصبع |

```python
دالة ارسم(س، ص):
    ل.ارسم_دائرة(س، ص، ٤، اللون=لاشيء، التعبئة="أسود")

ل = لوحة_رسم(٦٠٠، ٤٠٠، عند_السحب=ارسم)
ل.عند_الإفلات = لامدا: اطبع("انتهى الخط")    # أو بعد الإنشاء
```

على الهاتف، اللوحة التي تستقبل السحب لا تمرر الصفحة عند لمسها، فيعمل الرسم بالإصبع.

**السلحفاة** ترسم على لوحة (مثل مكتبة turtle في بايثون). تبدأ في المنتصف متجهة يمينًا:

```python
س = سلحفاة_رسم()            # تنشئ لوحة ٤٠٠×٤٠٠، أو: سلحفاة_رسم(لوحتي)
س.لون("بنفسجي")
لكل _ في مدى(٥):
    س.تقدم(١٥٠)
    س.يمين(١٤٤)
```

أوامرها: `تقدم`، `تراجع`، `يمين`، `يسار`، `اتجه`، `اذهب_إلى(س، ص)`، `دائرة(نصف_القطر)`،
`ارفع_القلم`، `أنزل_القلم`، `لون`، `سمك`.

## لوحة المفاتيح والألعاب

```python
@عند_ضغط_مفتاح
دالة حرك(المفتاح):
    إذا المفتاح == "يمين":
        ...

عند_رفع_مفتاح(لامدا م: اطبع("رُفع"، م))

دالة خطوة():                       # داخل مؤقت اللعبة
    إذا مفتاح_مضغوط("مسافة"):
        اقفز()

كرر_كل(٠.٠٥، خطوة)
```

- أسماء المفاتيح الخاصة بالعربية: «أعلى» «أسفل» «يمين» «يسار» «مسافة» «إدخال» «هروب»
  «حذف» «جدولة» «تبديل» «تحكم» «بديل»، والحروف والأرقام بأنفسها (`"a"`، `"ب"`، `"5"`).
- الضغطات داخل حقول الكتابة لا تُحسب، فالكتابة في التطبيق لا تحرّك اللعبة.
- الأسهم والمسافة لا تمرر الصفحة أثناء اللعب.
- عند التشغيل ينتقل التركيز إلى التطبيق تلقائيًا، فتعمل الأسهم دون نقرة إضافية.

المثال الكامل: [examples/gui/snake.af](../examples/gui/snake.af) (لعبة الثعبان).

## الصفحة

| | |
|---|---|
| `عنوان_الصفحة(النص)` | عنوان التطبيق (لسان المتصفح واسم الملف عند التصدير) |
| `تنبيه(الرسالة، النوع)` | رسالة قصيرة؛ النوع: «معلومة» «نجاح» «تحذير» «خطأ» |
| `امسح_الصفحة()` | يحذف كل العناصر |
| `سمة_الصفحة(اللون، الخلفية، الخط، الوضع)` | مظهر التطبيق كله: اللون الأساسي للأزرار والعناصر، والخلفية، وحجم الخط، والوضع «فاتح» أو «داكن» |
| `أكد(الرسالة، عند_الموافقة)` | نافذة تأكيد، انظر [النوافذ المنبثقة](#الألسنة-والنوافذ-المنبثقة) |
| `نزل_ملف(الاسم، المحتوى)` | تنزيل ملف، انظر [الملفات](#الملفات-الرفع-والتنزيل) |

```python
سمة_الصفحة(اللون="بنفسجي")
مفتاح_تبديل("الوضع الداكن"، عند_التغيير=لامدا د: سمة_الصفحة(الوضع="داكن" إذا د وإلا "فاتح"))
```

## النشر والتصدير

من لسان «الواجهة» في ساحة أفعى:

| الزر | ماذا يفعل |
|---|---|
| ↗ نافذة مستقلة | يفتح التطبيق وحده في لسان جديد |
| 🔗 رابط التطبيق | ينسخ رابطًا يفتح التطبيق مباشرة لأي أحد، **وهذا نشر فوري مجاني** (البرنامج محفوظ داخل الرابط نفسه) |
| ⬇ تصدير كموقع | ينزّل ملف zip فيه موقع كامل مستقل (نحو ١٠ ميغابايت): التطبيق وبايثون وأفعى |

**نشر الموقع المُصدَّر مجانًا:**

- **GitHub Pages:** أنشئ مستودعًا عامًا، وارفع محتويات الملف المضغوط، ثم
  Settings ← Pages ← Deploy from a branch ← main.
- **Netlify:** اسحب المجلد إلى https://app.netlify.com/drop

الموقع لا يحتاج خادمًا: يعمل في متصفح الزائر بالكامل. التفاصيل في ملف
«اقرأني.txt» داخل الملف المضغوط.

**من سطر الأوامر:** `afaa --web تطبيقي.af` يفتح ملفًا على جهازك كتطبيق ويب،
و`afaa --edit تطبيقي.af` يفتحه في المحرر.
