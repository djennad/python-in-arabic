# ستريمليت بالعربية: مواقع تفاعلية بلغة أفعى

[Streamlit](https://streamlit.io) مكتبة بايثون لبناء مواقع البيانات والتطبيقات التفاعلية بسطور
قليلة. مكتبة **ستريمليت** في أفعى تجعلها عربية بالكامل: أسماء الدوال، والمعاملات المسماة،
وقيم الخيارات، والحاويات، ورسائل الأخطاء.

```python
استورد ستريمليت باسم ست

ست.اضبط_الصفحة(عنوان_الصفحة="مرحبا"، أيقونة_الصفحة="👋")
ست.عنوان("👋 أول موقع بلغة أفعى")

الاسم = ست.حقل_نص("ما اسمك؟"، تلميح="اكتب اسمك هنا")
العمر = ست.منزلق("كم عمرك؟"، الأدنى=٥، الأقصى=٩٩، القيمة=٢٠)

إذا الاسم:
    ست.نجاح(f"أهلا يا {الاسم}! عمرك {العمر} سنة.")
    إذا ست.زر("احتفل 🎉"، نوع="أساسي"):
        ست.بالونات()
```

## كيف يعمل ستريمليت؟

البرنامج يُنفَّذ **من أوله إلى آخره عند كل تفاعل**: عندما يكتب الزائر في حقل أو يضغط زرًا،
يعاد تشغيل البرنامج كله، وتُرجع كل أداة قيمتها الحالية. لذلك لا توجد دوال أحداث كما في مكتبة
«واجهات»، بل تكتب البرنامج كأنه يُنفَّذ مرة واحدة:

```python
العدد = ست.حقل_عدد("اكتب عددًا"، القيمة=٥)
ست.اكتب(f"مربعه {العدد ** ٢}")      # يتحدث تلقائيًا عند تغيير العدد
```

لحفظ قيمة بين مرات التشغيل استعمل [حالة الجلسة](#حالة-الجلسة).

**أيهما أختار: «واجهات» أم «ستريمليت»؟**

- **واجهات**: أخف وأسرع تحميلًا، وتعتمد على الأحداث (دوال عند الضغط)، ومناسبة للألعاب
  والرسم والتطبيقات الصغيرة.
- **ستريمليت**: مناسبة لمواقع البيانات: رسوم بيانية، وجداول تفاعلية، ولوحات معلومات،
  ودردشة، بمظهر احترافي جاهز. تحميلها الأول أبطأ لأنها تحمّل Streamlit كاملة.

## التشغيل

**في ساحة أفعى:** اكتب البرنامج واضغط «تشغيل». أي برنامج يبدأ بـ `استورد ستريمليت`
يعمل في لسان «الواجهة» ببيئة Streamlit كاملة داخل المتصفح. التحميل الأول قد يستغرق دقيقة
(تُحفظ الملفات بعدها في المتصفح)، وكل تشغيل بعده يحدّث التطبيق في أقل من ثانية.
الأمثلة الجاهزة في قائمة الأمثلة تحت «مواقع ستريمليت».

**على جهازك:**

```bash
pip install streamlit
afaa --streamlit تطبيقي.af
```

يفتح المتصفح على `http://localhost:8501`، ويعيد Streamlit التشغيل عند حفظ الملف.
الخيارات الإضافية تمرَّر إلى Streamlit نفسها، مثل: `afaa --streamlit تطبيقي.af --server.port 8000`.

## النشر والتصدير

مثل تطبيقات «واجهات»، من لسان «الواجهة» في ساحة أفعى:

- **↗ نافذة مستقلة**: يفتح التطبيق وحده دون المحرر.
- **🔗 رابط التطبيق**: رابط فيه البرنامج كاملًا، من يفتحه يرى الموقع مباشرة. مجاني ولا يحتاج خادمًا.
- **⬇ تصدير كموقع**: ملف zip فيه الموقع كاملًا (نحو ٣٥ ميغابايت مضغوطًا لأنه يحمل بايثون وStreamlit)،
  ترفعه على GitHub Pages أو Netlify أو أي استضافة ملفات ثابتة. عنوان الموقع يؤخذ من
  `عنوان_الصفحة` في `ست.اضبط_الصفحة`.

ومن سطر الأوامر: `afaa --web تطبيقي.af` يطبع رابط التطبيق ويفتحه.

يمكنك أيضًا نشر التطبيق على [Streamlit Community Cloud](https://streamlit.io/cloud) المجاني:
ضع في المستودع ملف `تطبيقي.af`، وملف `requirements.txt` فيه السطر
`git+https://github.com/djennad/python-in-arabic`، وملف `streamlit_app.py` هذا:

```python
from afaa.streamlit_runner import run_file
run_file("تطبيقي.af")
```

## الحاويات والتخطيط

```python
مع ست.الشريط_الجانبي:
    المدينة = ست.قائمة_منسدلة("المدينة"، ["الجزائر"، "وهران"])

أ، ب، ج = ست.أعمدة(٣)
أ.مقياس("الزوار"، "١٢٠٠"، الفرق="+٥٪")
ب.مقياس("المبيعات"، ٣٤٠)

الأول، الثاني = ست.ألسنة(["📈 رسم"، "🗂️ جدول"])
مع الأول:
    ست.رسم_خطي({"المبيعات": [٣، ٥، ٤، ٨]})
الثاني.جدول_بيانات({"الاسم": ["أحمد"، "سارة"]})

مع ست.قابل_للطي("تفاصيل"):
    ست.اكتب("محتوى مطوي")
```

كل حاوية (الشريط الجانبي، عمود، لسان، `حاوية()`، `مكان_فارغ()`) تقبل الدوال العربية نفسها:
`أ.زر(...)` أو داخل `مع أ:`.

## حالة الجلسة

القيم العادية تُنسى عند كل تشغيل. `ست.حالة_الجلسة` تبقى طوال زيارة المستخدم:

```python
الحالة = ست.حالة_الجلسة
إذا "العدد" ليس في الحالة:
    الحالة["العدد"] = ٠
إذا ست.زر("زد"):
    الحالة["العدد"] += ١
ست.اكتب(f"العدد {الحالة['العدد']}")
```

يُفضَّل استعمال الأقواس والنصوص (`الحالة["العدد"]`) لأن النصوص لا تُترجم أبدًا.

ومعاملات الرابط (`?المدينة=وهران`) متاحة عبر `ست.معاملات_الرابط`.

## الاستمارات

داخل الاستمارة لا يعاد التشغيل حتى يُضغط زر الإرسال:

```python
مع ست.استمارة("تسجيل"، امسح_عند_الإرسال=صح):
    الاسم = ست.حقل_نص("الاسم")
    العمر = ست.حقل_عدد("العمر"، الأدنى=٠)
    أُرسلت = ست.زر_إرسال("سجّل")
إذا أُرسلت:
    ست.نجاح(f"سُجّل {الاسم}")
```

## التخزين المؤقت

الدوال البطيئة (قراءة ملفات، حسابات كبيرة) تُحفظ نتيجتها فلا تُعاد عند كل تفاعل:

```python
@ست.خزن_البيانات
دالة حمّل_البيانات():
    ...

@ست.خزن_البيانات(مدة_الصلاحية=٦٠)   # بالثواني
دالة الأسعار():
    ...
```

و`@ست.خزن_المورد` للكائنات المشتركة (مثل النماذج المدربة).

## مع قواعد البيانات

مكتبة [قواعد_البيانات](database.md) تعمل مع ستريمليت، والبيانات تبقى بعد إغلاق الموقع
(في ملف على الجهاز، أو في ذاكرة المتصفح الدائمة):

```python
استورد ستريمليت باسم ست
من قواعد_البيانات استورد *

ق = قاعدة_بيانات("مهامي")

صنف مهمة(نموذج):
    النص = عمود_نص(مطلوب=صح)
    منجزة = عمود_منطقي(افتراضي=خطأ)

ق.أنشئ_جداول(مهمة)
النص = ست.حقل_نص("مهمة جديدة")
إذا ست.زر("أضف") و النص:
    مهمة.أنشئ(النص=النص)
ست.جدول_بيانات([{"المهمة": م.النص، "منجزة": م.منجزة} لكل م في مهمة.الكل()])
```

المثال الكامل في [examples/streamlit/todo.af](../examples/streamlit/todo.af).

## الأخطاء

الأخطاء تظهر داخل التطبيق بالعربية، مع السطر من برنامجك دون تفاصيل Streamlit الداخلية:

```
حدث خطأ في البرنامج
  الملف "app.af"، السطر 3، في <الوحدة>
    اطبع(غير_معرف)
خطأ_اسم: الاسم 'غير_معرف' غير معرّف
```

واستعمال اسم غير موجود في المكتبة يعطي رسالة واضحة:
`لا يوجد في ستريمليت اسم «...». الأسماء الإنجليزية متاحة عبر ست.الأصل`.

## الأسماء الإنجليزية

كل ما في Streamlit متاح عبر `ست.الأصل` (وهي مكتبة `streamlit` نفسها):

```python
ست.الأصل.pydeck_chart(...)
```

والحاويات العربية تقبل الأسماء الإنجليزية مباشرة أيضًا: `ست.الشريط_الجانبي.slider(...)`.

## القيم العربية

بعض المعاملات تقبل قيمًا نصية عربية تُترجم تلقائيًا، مثل `نوع="أساسي"` و`التخطيط="واسع"`:

| المعامل | القيم العربية |
|---|---|
| `type` | `أساسي` (primary)، `ثانوي` (secondary)، `ثالثي` (tertiary) |
| `layout` | `واسع` (wide)، `وسط` (centered) |
| `initial_sidebar_state` | `مفتوح` (expanded)، `مغلق` (collapsed)، `تلقائي` (auto) |
| `label_visibility` | `ظاهر` (visible)، `مخفي` (hidden)، `مطوي` (collapsed) |
| `gap` | `صغير` (small)، `متوسط` (medium)، `كبير` (large) |
| `delta_color` | `عادي` (normal)، `معكوس` (inverse)، `رمادي` (off) |
| `vertical_alignment` | `أعلى` (top)، `وسط` (center)، `أسفل` (bottom) |
| `width` | `ملء` (stretch)، `المحتوى` (content) |
| `name` | `مستخدم` (user)، `مساعد` (assistant) |
| `selection_mode` | `واحد` (single)، `متعدد` (multi) |
| `divider` | `أزرق` (blue)، `أخضر` (green)، `برتقالي` (orange)، `أحمر` (red)، `بنفسجي` (violet)، `رمادي` (gray)، `قوس_قزح` (rainbow) |

وفي `ست.رسالة_دردشة("مستخدم")` و`ست.رسالة_دردشة("مساعد")` يُترجم اسم المتحدث كذلك.

## ملاحظات وحدود

- **التحميل الأول في المتصفح** أبطأ من «واجهات» (عشرات الميغابايتات)، ثم تُحفظ الملفات في المتصفح.
- **في المتصفح** تعمل الحزم المضمّنة فقط: pandas وnumpy وaltair وpillow. الحزم الأخرى
  تحتاج التشغيل على الجهاز (`afaa --streamlit`).
- **الصور والملفات من مواقع أخرى** قد يمنعها المتصفح داخل ساحة أفعى لأسباب أمنية؛
  ضع الصور بجانب الموقع المصدَّر أو استعمل روابط تسمح بذلك.
- **الأوامر السحرية** (كتابة متغير وحده في سطر ليُعرض) غير مدعومة: استعمل `ست.اكتب(...)`.
- **المنزلق** يبقى من اليسار إلى اليمين (القيم الصغرى يسارًا) كما في Streamlit.
- أسماء الخصائص المكتوبة بالنقطة (مثل `ست.حالة_الجلسة.الاسم`) قد تُترجم إن كانت من
  كلمات القاموس؛ النصوص بين الأقواس أوضح دائمًا.
