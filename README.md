# أفعى 🐍 — لغة برمجة عربية مطابقة لبايثون

**أفعى** لغة برمجة تُكتب بالعربية، قواعدها هي قواعد بايثون تمامًا: نفس الإزاحة،
ونفس التعابير، ونفس الأصناف والدوال والمولدات والبرمجة غير المتزامنة والمطابقة
الهيكلية... كل شيء. الفرق الوحيد أنك تكتب الكلمات بالعربية.

```python
دالة تحية(اسم):
    أرجع f"السلام عليكم يا {اسم}"

لكل اسم في ["أحمد"، "فاطمة"]:
    إذا اسم.يبدأ_ب("أ"):
        اطبع(تحية(اسم))
    وإلا:
        اطبع("أهلا", اسم)
```

## كيف تعمل؟

تترجم أفعى الشيفرة العربية إلى بايثون ثم تنفّذها بمفسّر بايثون نفسه (CPython).
لذلك:

- **تدعم كل خصائص بايثون** بلا استثناء، في كل إصدار من بايثون تعمل عليه.
- **تعمل معها كل مكتبات بايثون** (المكتبة القياسية ومكتبات pip)، ويمكن خلط ملفات
  أفعى (`.af`) مع ملفات بايثون (`.py`) في المشروع نفسه.
- **رسائل الأخطاء بالعربية** وتشير إلى السطر الصحيح في ملفك العربي.

## ساحة أفعى: جرّبها في المتصفح 🌐

**[djennad.github.io/python-in-arabic](https://djennad.github.io/python-in-arabic/)**

محرر ويب يعمل بالكامل في المتصفح، بلا تثبيت ولا خادم:

- تلوين الشيفرة العربية، وإكمال تلقائي يعرض مقابل كل كلمة في بايثون
  (مرن مع الهمزات: اكتب «اذا» فيقترح «إذا»)
- إزاحة تلقائية بعد النقطتين، وتمييز سطر الخطأ برسائل عربية
- دعم الإدخال `أدخل()`، وزر لإيقاف البرامج العالقة
- لوحة «بايثون المقابل» تعرض الترجمة أثناء الكتابة
- أمثلة جاهزة، وحفظ تلقائي، ومشاركة البرنامج برابط
- وضع فاتح وداكن، ويعمل على الهاتف

يعمل المحرر بمترجم أفعى نفسه على بايثون حقيقي داخل المتصفح (Pyodide)، فكل ما
يعمل على جهازك يعمل فيه. التحميل الأول يستغرق بضع ثوانٍ.

## تطبيقات ويب تفاعلية: مكتبة «واجهات» 🖼️

ابنِ تطبيقات ويب بالعربية: أزرار، وحقول إدخال، وجداول، ولوحات رسم، ومؤقتات.

```python
من واجهات استورد *

عنوان_الصفحة("عدّاد")
العدد = تسمية("٠")

دالة زد():
    العدد.النص = نص(عدد_صحيح(العدد.النص) + ١)

زر("زد واحدًا"، عند_الضغط=زد)
```

شغّله في ساحة أفعى فيظهر في لسان «الواجهة»، ومنه يمكنك:

- **↗ فتحه في نافذة مستقلة** دون المحرر
- **🔗 نشره فورًا برابط**: من يفتح الرابط يرى التطبيق مباشرة (مجانًا، البرنامج محفوظ في الرابط)
- **⬇ تصديره كموقع مستقل**: ملف zip تستضيفه على GitHub Pages أو Netlify أو أي مكان

ومن سطر الأوامر: `afaa --web تطبيقي.af` يفتح ملفًا على جهازك كتطبيق ويب.

التوثيق الكامل في [docs/gui.md](docs/gui.md)، والأمثلة في [examples/gui](examples/gui):
عدّاد، وحاسبة، وقائمة مهام، ولوحة رسم بالسلحفاة، وساعة إيقاف. المكتبة نفسها مكتوبة
بلغة أفعى: [afaa/lib/واجهات.af](afaa/lib/واجهات.af).

## قواعد البيانات: SQL بالعربية 🗄️

احفظ بيانات برامجك في قاعدة بيانات SQLite، واكتب الاستعلامات بالعربية:

```python
من قواعد_البيانات استورد قاعدة_بيانات

ق = قاعدة_بيانات("مدرستي")
ق.نفذ("أنشئ جدول إذا لم يوجد الطلاب (الاسم نص غير فارغ، العمر عدد_صحيح)")
ق.نفذ("أدخل إلى الطلاب القيم (؟، ؟)"، "أحمد"، ١٦)

لكل طالب في ق.استعلم("اختر * من الطلاب حيث العمر أكبر من ١٥ رتب حسب الاسم"):
    اطبع(طالب["الاسم"])
```

- **SQL عربي كامل:** `اختر` (SELECT)، `من` (FROM)، `حيث` (WHERE)، `رتب حسب` (ORDER BY)،
  `جمّع حسب` (GROUP BY)، `أدخل إلى` (INSERT INTO)، `حدث` (UPDATE)، `احذف` (DELETE)،
  `ضم` (JOIN)، `مفتاح أساسي` (PRIMARY KEY)، ودوال مثل `عد` و`مجموع` و`متوسط`.
- **تبقى البيانات بعد الإغلاق:** على الجهاز في ملف `مدرستي.db`، وفي المتصفح في ذاكرته الدائمة.
- **أخطاء بالعربية** مع الاستعلام الأصلي، ومعاملات تُلغى كلها عند الخطأ.
- **مع «واجهات»:** `جدول(ق.استعلم("اختر * من الطلاب"))` يعرض النتائج مباشرة.
- **طرفية SQL عربية** للتعلم: `afaa --sql مدرستي`.
- **النماذج (ORM):** جداول على شكل أصناف واستعلامات دون SQL:

  ```python
  صنف طالب(نموذج):
      الاسم = عمود_نص(مطلوب=صح)
      العمر = عمود_عدد_صحيح()

  ق.أنشئ_جداول(طالب)
  طالب.أنشئ(الاسم="أحمد"، العمر=١٦)
  طالب.حيث(طالب.العمر > ١٥).رتب(-طالب.العمر).الكل()
  ```

التوثيق الكامل والقاموس في [docs/database.md](docs/database.md)، ومثال تطبيق كامل في
[examples/gui/students.af](examples/gui/students.af).

## الاستخدام

| الأمر | الوظيفة |
|---|---|
| `afaa` | الطرفية التفاعلية |
| `afaa ملف.af` | تشغيل ملف |
| `afaa ملف.af أ ب` | تشغيل ملف مع معاملات (`نظام.معاملات_التشغيل`) |
| `afaa -c "اطبع(١ + ١)"` | تشغيل شيفرة مباشرة |
| `afaa -m وحدة` | تشغيل وحدة كبرنامج رئيسي |
| `afaa -i ملف.af` | تشغيل ملف ثم فتح الطرفية |
| `afaa --translate ملف.af` | عرض شيفرة بايثون المقابلة |
| `afaa --to-arabic ملف.py` | تحويل ملف بايثون إلى أفعى |
| `afaa --sql مدرستي` | طرفية SQL بالعربية على قاعدة بيانات |
| `afaa --translate-sql "اختر * من ط"` | عرض استعلام SQL عربي بالإنجليزية |
| `afaa --web ملف.af` | فتح الملف كتطبيق ويب في المتصفح (لبرامج «واجهات») |
| `afaa --edit ملف.af` | فتح الملف في ساحة أفعى |
| `afaa --vocabulary` | عرض القاموس كاملًا |

يمكن أيضًا استخدامها من بايثون:

```python
import afaa
afaa.run_source("اطبع(«مرحبا»)")
print(afaa.translate("لكل س في مدى(٣): اطبع(س)"))
```

## جولة سريعة

### المتغيرات والأرقام العربية

```python
الاسم = «أحمد»          # يمكن استخدام «» أو "" أو ''
العمر = ٢٥              # الأرقام العربية ٠-٩ أو الإنجليزية 0-9
الطول = ١٫٧٥            # الفاصلة العشرية العربية ٫
مليون = ١٬٠٠٠٬٠٠٠        # فاصل الآلاف ٬
اطبع(الاسم، العمر، فاصل=" | ")   # الفاصلة العربية ، مقبولة
```

### الشروط والحلقات

```python
إذا الدرجة >= ٩٠:
    اطبع("ممتاز")
وإلا إذا الدرجة >= ٨٠:      # أو: وإلا_إذا
    اطبع("جيد جدا")
وإلا:
    اطبع("جيد")

لكل ع في مدى(١٠):
    إذا ع == ٣: استمر
    إذا ع == ٧: اكسر

طالما صح:
    اكسر
```

### الدوال

```python
دالة اجمع(أ، ب=٠، *معطيات، **معطيات_مسماة):
    """التوثيق هنا"""
    أرجع أ + ب

مربع = لامدا س: س ** ٢

دالة عد_تنازلي(ن):          # مولّد
    طالما ن > ٠:
        أنتج ن
        ن -= ١
```

### الأصناف

```python
صنف حيوان:
    دالة __تهيئة__(ذات، اسم):
        ذات.اسم = اسم

    دالة __نص__(ذات):
        أرجع f"حيوان اسمه {ذات.اسم}"

صنف قطة(حيوان):
    دالة __تهيئة__(ذات، اسم):
        الأب().__تهيئة__(اسم)

    @خاصية
    دالة صوت(ذات):
        أرجع "مياو"
```

## قواعد مفيدة

- **الهمزات والحركات مرنة:** `إذا` و`اذا` و`إذَا` كلها صحيحة، وكذلك `أرجع`/`ارجع`،
  و`مدى`/`مدي`، و`دالة`/`داله`.
- **الأسماء الخاصة بك** تبقى كما كتبتها (بايثون يقبل المتغيرات العربية أصلًا).
- **النصوص والتعليقات لا تُترجم أبدًا**، لكن التعابير داخل `{}` في النصوص المنسقة
  (f-strings) تُترجم.
- **الكلمات تُكتب منفصلة:** اكتب `و ليس` لا `وليس`.
- **الترجمة ثابتة:** كل كلمة في القاموس تُترجم في كل مكان، فالمتغير `مفتاح` يصبح
  `key` في بايثون. هذا لا يؤثر على عمل برنامجك لأن الترجمة متسقة، لكن انتبه
  عند استخدام أسماء الخصائص كنصوص (مثل `اجلب_خاصية(ك، "اسم")`).
- **قيم بايثون تُطبع بالإنجليزية:** `اطبع(صح)` يطبع `True`، لأن أفعى تستخدم
  كائنات بايثون نفسها.
- `نفذ` و`قيم` (exec و eval) تقبلان شيفرة أفعى العربية.
